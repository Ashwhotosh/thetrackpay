## Setup tips for Google Forms

- Use **Settings → Make this a quiz: OFF**, but turn on **"Collect email addresses" = Off** (let Q15 handle it optionally, so people who say "No" aren't forced to give an email).
- Turn on **"Shuffle question order": OFF** — keep it in this narrative order (problem → product → competitors → reaction).
- Add **Section breaks** exactly where marked above so it doesn't feel like a long scroll.
- For Q15, use Forms' **branching**: "Go to section based on answer" on Q14 so only "Yes" respondents see the email field.
- Keep total questions under ~15 like this — anything longer kills completion rate for a cold-outreach form shared under a YouTube video.
